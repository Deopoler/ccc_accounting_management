# 테스트

```sh
flutter analyze
flutter test                                    # 단위 테스트 + 반응형 레이아웃 테스트

cd supabase/tests && npm install && npm test    # DB (RLS / 권한 / RPC / 트리거)
```

CI 는 테스트 서버 적용과 운영 배포 전에 셋 다 실행하고, 실패하면 DB 를 바꾸지 않는다.

## DB 테스트

실제 Supabase 없이 PGlite(WASM Postgres)에 Supabase 의 `auth` 스키마와 롤을 흉내 내어([supabase_stub.sql](../../supabase/tests/supabase_stub.sql))
마이그레이션을 적용한 뒤, `authenticated` / `anon` 롤로 SQL 을 실행해 검증한다.

- **마이그레이션을 추가하면 반드시 `npm test` 를 실행한다.**
- 새 함수를 `authenticated` 가 실행할 수 있게 하면 `security.test.mjs` 의 허용 목록에도 넣어야 한다.
- 데이터 이전이 있는 마이그레이션은 `createDbBefore(버전)` 로 직전 상태를 만들고 `applyMigration` 으로 적용해 검증한다.
