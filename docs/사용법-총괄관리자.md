# CCC 회계 사용법: 총괄 관리자

총괄 관리자는 **모든 캠퍼스**를 관리하고, 새 캠퍼스를 추가하고, 다른 총괄 관리자를 지정합니다.

**🔗 접속 주소: <https://deopoler.github.io/ccc_accounting_management/>**

[← 사용법 목록](사용법.md) · 화면 사진은 예시 데이터로 찍었습니다.

> 💡 총괄 관리자는 캠퍼스 관리자 기능을 모든 캠퍼스에서 씁니다. 회원 · 교재 · 신청 · 이벤트 · 계좌 관리 방법은 [캠퍼스 관리자 사용법](사용법-캠퍼스관리자.md)을 보세요. 이 문서는 **총괄 관리자에게만 있는 기능**을 다룹니다.

## 1. 캠퍼스 관리자와 다른 점

| 기능 | 캠퍼스 관리자 | 총괄 관리자 |
| --- | --- | --- |
| 관리할 수 있는 캠퍼스 | 자기 캠퍼스 | **모든 캠퍼스** (전환해서 관리) |
| 캠퍼스 추가 · 이름 변경 | ✕ | ○ |
| 캠퍼스 관리자 지정 / 해제 | 자기 캠퍼스 | 모든 캠퍼스 |
| 캠퍼스의 마지막 캠퍼스 관리자 해제 | ✕ | ○ |
| 총괄 관리자 지정 / 해제 | ✕ | ○ |
| 총괄 관리자 계정 관리 (비밀번호 초기화 등) | ✕ | ○ |

> 💡 회원 화면(교재 신청, 내 신청, 이벤트)은 총괄 관리자도 **본인 캠퍼스** 기준으로 보입니다.

---

## 2. 관리할 캠퍼스 바꾸기

관리자 화면(회원 / 교재 / 신청 현황 / 이벤트 / 설정)은 **지금 관리 중인 캠퍼스** 하나를 기준으로 보입니다.
화면 제목 옆에 캠퍼스 이름이 붙습니다. 예) `회원 관리 · KAIST`

캠퍼스를 바꾸는 방법은 두 가지입니다.

- 왼쪽 메뉴(휴대폰은 **관리** 탭 위쪽)의 **관리 중인 캠퍼스** 드롭다운에서 고릅니다.
- **캠퍼스 관리**에서 캠퍼스 옆 **더보기(⋮) → 이 캠퍼스 관리하기**를 누릅니다.

<img src="images/18-admin-hub-mobile.png" alt="관리 중인 캠퍼스 선택" width="300">

> ⚠️ 작업 전에 제목 옆 캠퍼스 이름을 꼭 확인하세요. 다른 캠퍼스의 데이터를 고칠 수 있습니다.

---

## 3. 캠퍼스 관리

**관리 → 캠퍼스 관리** 메뉴는 총괄 관리자에게만 보입니다.

- **캠퍼스 추가**: 이름(예: 서울대)과 코드(예: snu)를 입력합니다.
  - 코드는 회원 로그인 아이디(`학번@snu.ccc.local`)에 쓰이므로 **나중에 바꿀 수 없습니다.** 영문 소문자·숫자로 짧게 정하세요.
- **이름 변경**: 화면에 보이는 이름만 바뀝니다. 코드와 로그인 아이디는 그대로입니다.
- **이 캠퍼스 관리하기**: 관리자 화면을 그 캠퍼스로 바꿉니다. 지금 관리 중인 캠퍼스에는 **관리 중** 표시가 붙습니다.

![캠퍼스 관리](images/17-admin-campuses.png)

## 4. 새 캠퍼스 시작하기

1. **캠퍼스 관리 → 캠퍼스 추가**로 캠퍼스를 만듭니다.
2. 그 캠퍼스의 회계 담당자에게 앱 주소를 알려 주고, 가입 화면에서 **새 캠퍼스를 골라 가입**하게 합니다.
3. **관리 중인 캠퍼스**를 새 캠퍼스로 바꿉니다.
4. **회원 관리**에서 담당자의 가입을 **승인**하고, **더보기(⋮) → 캠퍼스 관리자로 지정**합니다.
5. 이후 회원 승인, 교재 등록, 송금 계좌 설정은 그 캠퍼스 관리자가 직접 할 수 있습니다.
   필요하면 총괄 관리자가 **설정 → 송금 계좌**와 **교재 관리**를 먼저 채워 둬도 됩니다.

> 💡 캠퍼스가 둘 이상이면 로그인 · 가입 화면에 **캠퍼스** 선택 칸이 나타납니다. 기존 회원도 로그인할 때 자기 캠퍼스를 골라야 합니다. (마지막으로 쓴 캠퍼스는 브라우저에 기억됩니다)

## 5. 관리자 지정과 해제

**회원 관리**에서 회원 옆 **더보기(⋮)** 를 누릅니다.

![회원 관리](images/11-admin-members.png)

| 메뉴 | 결과 |
| --- | --- |
| 캠퍼스 관리자로 지정 / 해제 | 지금 관리 중인 캠퍼스의 관리자가 됩니다 / 회원으로 돌아갑니다 |
| 총괄 관리자로 지정 | 모든 캠퍼스의 회계 데이터를 보고 고치며, 캠퍼스를 추가할 수 있게 됩니다 |
| 총괄 관리자 해제 | **캠퍼스 관리자**로 남습니다 (자기 캠퍼스만 관리) |

지켜지는 규칙:

- **마지막 총괄 관리자**는 해제할 수 없습니다. 교체할 때는 새 총괄 관리자를 먼저 지정하세요.
- 본인 계정은 메뉴가 비활성화됩니다. 내 권한은 다른 총괄 관리자가 바꿔야 합니다.
- 캠퍼스 관리자는 자기 캠퍼스의 마지막 캠퍼스 관리자를 해제할 수 없지만, 총괄 관리자는 할 수 있습니다. (담당자 교체 · 캠퍼스 정리용)
- 총괄 관리자 지정은 꼭 필요한 사람에게만 하세요. 모든 캠퍼스의 회원 정보와 회계 기록에 접근할 수 있습니다.

## 6. 기본 비밀번호

**회원 관리 → 비밀번호 초기화**를 하면 회원 비밀번호가 **기본 비밀번호**로 바뀝니다.

- 기본 비밀번호는 보안을 위해 앱이나 데이터베이스에 저장하지 않고, 서버 설정에만 둡니다.
- 바꾸는 곳: Supabase Dashboard → **Edge Functions → Secrets → `DEFAULT_PASSWORD`**
- 캠퍼스 관리자들이 회원에게 알려 줄 수 있도록 기본 비밀번호를 공유해 주세요.

## 7. 자주 묻는 질문

**Q. 관리자 화면에 다른 캠퍼스 데이터가 보여요.**
**관리 중인 캠퍼스**가 다른 캠퍼스로 선택되어 있습니다. 메뉴에서 원래 캠퍼스로 바꾸세요.

**Q. 회원이 캠퍼스를 잘못 골라 가입했어요.**
그 캠퍼스로 전환한 뒤 **회원 관리**에서 가입을 **거절**하세요. 계정이 삭제되면 회원이 올바른 캠퍼스로 다시 가입할 수 있습니다.

**Q. 캠퍼스 코드를 잘못 만들었어요.**
코드는 바꿀 수 없습니다. 아직 가입한 회원이 없다면 새 캠퍼스를 만들어 쓰세요. 쓰지 않는 캠퍼스 삭제는 개발 담당자에게 요청해야 합니다.

**Q. 캠퍼스 관리자가 모두 그만뒀어요.**
그 캠퍼스로 전환해 새 담당자를 **캠퍼스 관리자로 지정**하고, 기존 담당자의 권한을 해제하세요.
