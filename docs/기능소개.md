# CCC 회계 기능 소개

**교재 신청과 이벤트 송금을 한곳에서.**
CCC 회계는 캠퍼스 동아리의 교재 주문과 수련회·순여행 같은 이벤트 회비를 관리하는 웹앱입니다.
회원은 휴대폰으로 교재를 신청하고 송금 안내를 확인하며, 회계 담당자는 입금 확인부터 배송, 미납자 관리까지 한 화면에서 처리합니다.

📖 **자세한 사용법**: [사용법.md](사용법.md)

## 이런 점이 편해집니다

| 이전 | CCC 회계 |
| --- | --- |
| 단톡방·구글폼으로 교재 신청을 받고 엑셀로 정리 | 회원이 직접 신청하고, 교재별 수량·금액이 자동 집계 |
| 누가 입금했는지 통장 내역과 명단을 대조 | 입금자명 형식을 정해 두고 체크 한 번으로 입금 확인 |
| 교재를 받았는지 일일이 확인 | 배송 처리 → 회원이 직접 수령 확인 |
| 미납자를 골라 개별 연락 | 미납자 명단을 한 번에 복사하거나 CSV로 내려받기 |
| 캠퍼스마다 따로 관리 | 여러 캠퍼스가 하나의 앱을 쓰고, 데이터는 캠퍼스별로 분리 |

## 회원 기능

### 📚 교재 신청

- **매주 회차제**: 수요일 오전 9시에 시작해 다음 주 수요일 오전 9시에 마감됩니다. 마감 전까지는 수정·취소할 수 있습니다.
- **카테고리별로 고르기**: 예) *새생활의 시작*, *cru.comm*. 여러 카테고리의 교재를 한 번에 신청하고, 교재명으로 검색할 수 있습니다.
- **송금 안내**: 신청이 끝나면 합계 금액과 캠퍼스 계좌가 나오고, 버튼 한 번으로 복사됩니다.
- **진행 상황 확인**: 신청 → 입금확인, 배송 전 → 배송됨 → 수령 완료.

### 💸 이벤트 송금

- 내가 송금해야 하는 이벤트와 **완납 / 미납** 여부를 한눈에 볼 수 있습니다.
- 이벤트마다 **금액 · 마감일(D-day) · 계좌 · 입금자명**이 안내되고, 모두 복사할 수 있습니다.
- 개인별로 조정된 금액이 있으면 그 금액이 표시됩니다.

### 🏠 홈

이번 회차 신청과 입금 대기 금액, 받아야 할 교재, 미납 이벤트를 첫 화면에서 요약해 보여 줍니다.

### 기타

- 휴대폰에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
- 라이트 / 다크 테마를 지원합니다.

## 관리자 기능

![교재 신청 현황](images/13b-admin-orders-table.png)

### 👥 회원 관리

- 회원이 직접 가입하고, 관리자가 **승인**한 뒤에 이용할 수 있습니다. 여러 명을 한 번에 승인할 수 있습니다.
- 비밀번호 초기화, 캠퍼스 관리자 / 총괄 관리자 지정을 할 수 있습니다.

### 📖 교재 관리

- 카테고리와 교재를 추가하고, 가격과 순서를 정합니다.
- **신청 가능** 스위치로 판매를 잠시 멈출 수 있습니다.

### ✅ 교재 신청 현황

- 회차별로 신청 목록을 봅니다. 화살표나 달력으로 지난 회차를 찾아갈 수 있습니다.
- **입금확인 · 배송 · 수령**을 체크하고, 현재 목록 전체를 한 번에 처리할 수도 있습니다.
- **교재별 집계**로 주문할 수량과 금액을 바로 확인합니다.
- 신청 목록과 집계를 **CSV**(엑셀·구글 시트)로 내려받습니다.

### 🎉 이벤트 관리

![이벤트 송금 현황](images/15-admin-event-detail.png)

- 이벤트를 만들고 **송금 대상**을 고릅니다. 전체 선택이나 검색 결과 전체 선택도 할 수 있습니다.
- **입금자명 형식**을 정할 수 있습니다. 예) `{이름}수련회` → 홍길동수련회
- **송금률과 수금액**을 막대로 보여 주고, 체크 한 번으로 송금을 확인합니다.
- 장학금이나 할인처럼 **개인별 금액**을 따로 정할 수 있습니다.
- **미납자 복사**로 단톡방에 공지하거나 CSV로 내려받습니다.

### ⚙️ 설정 · 캠퍼스

- 캠퍼스마다 송금 계좌를 설정합니다.
- 총괄 관리자는 캠퍼스를 추가하고, 관리할 캠퍼스를 바꿔 가며 모든 캠퍼스를 관리합니다.

## 역할

| 역할 | 할 수 있는 일 |
| --- | --- |
| 회원 | 교재 신청, 내 신청 관리, 이벤트 송금 확인 |
| 캠퍼스 관리자 | 회원 기능 + 자기 캠퍼스의 회원 · 교재 · 신청 · 이벤트 · 계좌 관리 |
| 총괄 관리자 | 모든 캠퍼스 관리, 캠퍼스 추가, 총괄 관리자 지정 |

## 안전하게 만들었습니다

- 회원은 **자기 정보만**, 캠퍼스 관리자는 **자기 캠퍼스 정보만** 볼 수 있습니다. 화면뿐 아니라 서버(데이터베이스)에서도 막습니다.
- 마감된 회차나 입금확인된 신청은 서버가 수정을 막습니다.
- 비밀번호 초기화에 쓰는 기본 비밀번호는 앱이나 데이터베이스에 저장하지 않습니다.

> 화면 사진은 예시 데이터로 찍었습니다. 실제 회원 정보가 아닙니다.
