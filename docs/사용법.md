# CCC 회계 사용법

CCC 회계는 **교재 신청**과 **이벤트 송금**을 한곳에서 관리하는 웹앱입니다.

**🔗 접속 주소: <https://deopoler.github.io/ccc_accounting_management/>**

기능을 간단히 둘러보려면 [기능 소개](기능소개.md)를 먼저 보세요.

## 내 역할에 맞는 사용법 보기

| 역할 | 누구 | 사용법 |
| --- | --- | --- |
| 회원 | 교재를 신청하고 회비를 내는 모든 회원 | [📘 회원 사용법](사용법-회원.md) |
| 캠퍼스 관리자 | 캠퍼스 회계 담당자 | [📗 캠퍼스 관리자 사용법](사용법-캠퍼스관리자.md) |
| 총괄 관리자 | 여러 캠퍼스를 함께 관리하는 담당자 | [📕 총괄 관리자 사용법](사용법-총괄관리자.md) |

- 캠퍼스 관리자는 회원 기능도 함께 씁니다.
- 총괄 관리자는 캠퍼스 관리자 기능을 모든 캠퍼스에서 씁니다.

> 💡 PC·휴대폰 브라우저 모두에서 쓸 수 있습니다. 휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 설치해 쓰면 편합니다.
