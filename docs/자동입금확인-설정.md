# 자동 입금 확인 설정 안내 (Android MacroDroid)

회계 담당자 휴대폰에 오는 은행 입금 알림을 CCC 회계 서버로 전달해 교재 신청과 이벤트 송금을 자동으로 확인하는 방법입니다. 현재 토스뱅크 알림 형식을 지원합니다.

## 1. 웹앱에서 먼저 설정하기

1. 캠퍼스 관리자(또는 총괄 관리자)로 로그인해 **관리자 > 설정 > 자동 입금 확인** 카드로 이동합니다.
2. **계좌 별칭**에 은행 알림에 표시되는 모임 계좌 이름을 입력합니다. (예: `KAIST CCC`)
   - 공백을 제외하고 4자 이상이어야 하며, `토스뱅크` · `모임통장` · `회비통장`처럼 개인 계좌와 겹칠 수 있는 일반적인 이름은 사용할 수 없습니다.
   - 이 문구가 포함되지 않은 개인 계좌 알림은 서버가 원문을 저장하지 않고 즉시 무시합니다.
3. **자동 입금 확인** 스위치를 켜고 **설정 저장**을 누릅니다.
4. **알림 수집 주소** 옆 복사 버튼을 눌러 주소를 복사해 둡니다.
   - 주소 형식: `https://<프로젝트>.supabase.co/functions/v1/deposit-ingest`
5. **토큰 발급**을 눌러 `X-Deposit-Token` 값을 발급받고 즉시 복사합니다.
   - 보안상 토큰 원문은 발급 직후 한 번만 보입니다. 창을 닫아 잊어버렸다면 **토큰 재발급**을 눌러 새로 발급받으세요.

## 2. MacroDroid 설치와 권한 허용 (Android)

1. Google Play 스토어에서 **MacroDroid**를 설치합니다.
2. MacroDroid가 은행 알림을 읽고 백그라운드에서 전송할 수 있도록 아래 권한을 허용합니다.
   - 알림 접근 권한 (Notification Access)
   - 배터리 최적화 제외 (백그라운드 중단 방지)

## 3. MacroDroid 매크로 만들기

새 매크로를 만들고 트리거와 동작을 아래 내용대로 설정합니다. (앱 버전에 따라 메뉴 이름은 조금 다를 수 있습니다.)

### 트리거 (언제 실행할지)

- 종류: **알림 수신 (Notification Received)**
- 대상 앱: **토스 (`viva.republica.toss`)** 선택
- 선택 사항(권장): 알림 내용 필터에 캠퍼스 계좌 별칭(예: `KAIST CCC`)을 넣으면 개인 계좌 알림이 휴대폰 밖으로 나가지 않습니다. 서버도 동일한 계좌 별칭으로 한 번 더 걸러냅니다.

### 동작 (무엇을 보낼지)

- 종류: **HTTP 요청 (HTTP Request)**
- 메서드: `POST`
- URL: 1단계에서 복사한 **알림 수집 주소**
- 요청 헤더:
  - `Content-Type`: `application/json`
  - `X-Deposit-Token`: 1단계에서 발급받은 **토큰**
- 요청 본문 (JSON):

```json
{
  "title": "{not_title}",
  "text": "{not_text}",
  "app_package": "{not_app_package}",
  "timestamp": "{unix_timestamp}"
}
```

> **`timestamp`는 반드시 포함해야 합니다.** MacroDroid 변수 삽입 버튼(매직 텍스트)으로 알림 제목, 알림 본문, 앱 패키지, Unix 타임스탬프 변수를 선택해 넣으세요. 변수 표기는 MacroDroid 버전에 따라 `[not_title]`처럼 대괄호를 쓸 수 있으니 직접 타이핑하지 말고 앱 안의 변수 선택기에서 고르는 것이 안전합니다.
>
> 긴 알림이 잘린다면 알림 본문 변수 대신 확장 알림 텍스트 변수를 사용하세요. JSON 안에 따옴표나 줄바꿈이 들어갈 수 있으므로 MacroDroid HTTP 요청 설정에서 JSON 이스케이프 옵션이 있으면 켜 두세요.
>
> **중복 방지와 재시도 안내**: 네트워크 오류나 `5xx` 응답으로 같은 요청을 재전송할 때, **처음 보냈던 것과 동일한 `timestamp`**(또는 동일한 `external_id`)를 함께 보내야 서버가 정확히 중복으로 걸러냅니다. 같은 내용의 알림이 **60초 안에** 다른 시각(또는 누락된 `timestamp`, 다른 `external_id`)으로 다시 들어오면 서버는 실제 연속 입금을 놓치지 않기 위해 버리지 않고 검토 목록(중복 의심)에 올려 자동 확인을 막습니다. 시간대가 없는 날짜 문자열(`YYYY-MM-DD HH:mm:ss`, `YYYY/MM/DD HH:mm:ss`, `YYYY.MM.DD HH:mm:ss`)은 한국 시간(`Asia/Seoul`, `+09:00`)으로 처리하며, 알 수 없는 형식은 서버 수신 시각으로 대체합니다.

## 4. 연결 테스트하기

### 1단계: 핑(연결) 테스트

은행 이체 전에 토큰과 주소가 맞는지 먼저 확인합니다. MacroDroid의 테스트 동작이나 PC/휴대폰 HTTP 테스트 도구로 아래 본문을 `POST` 합니다.

```json
{
  "ping": true
}
```

- 응답이 `200` 이고 `{"ok": true, "status": "pong"}` 이면 연결 성공입니다.
- 웹앱 **설정 > 자동 입금 확인 > 수신 상태**의 **마지막 수신** 시각이 방금 시각으로 바뀌었는지 확인합니다.

### 2단계: 소액(1원 또는 100원) 실제 이체 테스트

1. 본인 계좌에서 캠퍼스 계좌로 1원 또는 100원을 송금합니다.
2. 토스 알림이 휴대폰에 도착한 뒤 웹앱의 **관리자 > 입금 내역**과 **설정 > 수신 상태**를 확인합니다.
   - **입금 내역 > 미매칭**에 입금자명과 금액이 정확히 보이면 파서가 정상 동작하는 것입니다. (테스트 건은 **무시** 처리하세요.)
   - **입금 내역 > 해석 실패**에 들어가면 카드 안의 **원본 알림(제목 · 내용)**을 확인해 개발자에게 전달해 주세요. 파서를 실제 형식에 맞게 고친 뒤 **다시 해석** 버튼으로 다시 처리할 수 있습니다.
   - 입금 내역에는 아무것도 없는데 **설정 > 마지막 무시**가 갱신됐다면 아래 문제 해결 표를 확인하세요.

## 5. 문제 해결

| 증상 | 확인하고 고칠 것 |
| --- | --- |
| 응답 `401` | `X-Deposit-Token` 헤더 이름이나 토큰 값에 오타 · 공백이 있는지 확인하세요. 필요하면 토큰을 재발급합니다. |
| 응답 `403` | 웹앱 **설정 > 자동 입금 확인** 스위치가 켜져 있고 **계좌 별칭**이 저장되어 있는지 확인하세요. |
| 응답 `429` | 캠퍼스당 분당 60건 제한을 넘었습니다. MacroDroid 매크로가 무한 반복되고 있지 않은지 확인하세요. |
| **마지막 무시**에 `계좌 별칭 없음 (개인 계좌 등)` 이 뜸 | 실제 토스 알림에 웹앱에 적은 **계좌 별칭** 문구가 그대로 들어 있는지 확인하고, 실제 알림 문구에 맞게 계좌 별칭을 수정하세요. |
| **마지막 수신** 시각이 오래 멈춰 있음 | 휴대폰 재부팅 후 MacroDroid 알림 접근 권한이나 배터리 최적화 제외 설정이 풀렸는지 확인하세요. |

## iPhone (추후 지원)

iOS는 서드파티 앱이 다른 앱의 푸시 알림을 읽을 수 없어, 추후 은행 SMS 입금 문자를 iPhone **단축어(Shortcuts)** 자동화로 전달하는 방식으로 지원할 예정입니다. 같은 수집 주소와 `X-Deposit-Token` 헤더, 동일한 JSON 형식(`text`, 선택 `title`, `app_package: "ios.shortcuts.sms"`, `timestamp`)을 그대로 쓰며 SMS 파서만 추가하면 연동됩니다.
